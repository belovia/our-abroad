# AGENTS

How agents should work in this repository.

Product norm (as-is): `SSOT.md` → `openspec/docs/ssot/`. Governance: `openspec/docs/SSOT_GOVERNANCE.md`.

How Matt Pocock skills and OpenSpec fit together: `docs/agents/WORKING-WITH-SKILLS-AND-OPENSPEC.md`.

## Agent skills

### Issue tracker

Local markdown under `.scratch/<feature>/` (spec + one file per ticket). See `docs/agents/issue-tracker.md`.

### Triage labels

Default roles as `Status:` on issue files: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `SSOT.md` + `openspec/docs/ssot/` as product norm; `GLOSSARY.md` and `docs/adr/` created lazily by domain skills. See `docs/agents/domain.md`.
